PHASE 5.67 - MOBILE GLOBAL FLOATING OPERATIONAL MENU

Fecha: 2026-07-10 06:24:21

Objetivo:
- Crear un menú operativo flotante global.
- Que esté disponible en cualquier pantalla móvil.
- Que no dependa del Home.
- Que muestre únicamente las opciones permitidas por la matriz de permisos.
- Que permita navegar directamente a cada módulo.

Cambios aplicados:
- Se crea:
  src/Navi.ToolsAssets.MobilePwa/Components/Shared/NaviMobileFloatingMenu.razor

- Se modifica:
  src/Navi.ToolsAssets.MobilePwa/Layout/MainLayout.razor

- Se modifica:
  src/Navi.ToolsAssets.MobilePwa/wwwroot/css/app.css

Comportamiento:
- Botón flotante de tres rayitas arriba a la izquierda.
- Al presionar, abre panel flotante del menú operativo.
- Al presionar fuera, se cierra.
- Al seleccionar una opción, navega y se cierra.
- Se oculta en login/logout o sin autenticación.
- Se oculta el panel operativo antiguo del Home para evitar duplicidad.

Permisos:
- Dashboard.View -> Dashboard.
- Tools.View -> Inventario AF.
- AssetAvailability.* -> Disponible y ubicación.
- AssetAssignment.* / Mobile.Loans.Request -> Asignación y préstamos.
- AssetAssignment.History -> Historial.
- TechnicalLifeRecord.View / ToolDetail.LifeRecord.Open -> Hoja de vida AF.
- Purchases.* -> Solicitar compra.
- Maintenance.* -> Solicitar mantenimiento.
- Purchases.View / Maintenance.View -> Consulta Compras y Mtto.
- MaintenancePlans.* -> Planes mantenimiento.
- PhysicalCounts.* -> Tomas físicas.
- Reconciliation.* -> Conciliación.
- Documents.* -> Documentos.
- Reports.* -> Reportes.
- Settings.* / Security.* -> Configuración.

Validación esperada:
- El botón ☰ se ve en todas las pantallas móviles autenticadas.
- El menú abre como ventana flotante.
- Las opciones dependen de permisos.
- Al seleccionar una opción navega correctamente.
- El menú no aparece en login.
- El Home no muestra duplicado el panel antiguo de Menú operativo.
