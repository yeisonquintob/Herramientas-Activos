PROMPT 4: ESTANDARIZACIÓN DE BOTONES DEL ADMIN WEB

Fecha: 2026-07-02 17:44:15

Objetivo:
Unificar todos los botones del Admin Web con un diseño compacto, consistente y fácil de mantener.

Archivo modificado:
- src/Navi.ToolsAssets.Admin/wwwroot/app.css

Reglas visuales aplicadas:
1. Botón normal: 30px de alto.
2. Botón pequeño: 27px de alto.
3. Botón extra pequeño: 24px de alto.
4. Radio uniforme.
5. Texto compacto y fuerte.
6. Botón primario morado.
7. Botón secundario outline azul/morado.
8. Botón éxito verde.
9. Botón peligro rojo.
10. Botón advertencia amarillo/naranja.
11. Botón info azul/cian.
12. Botones de tabla reducidos a 26px.
13. Botones de formulario alineados.
14. Botones de encabezado respetan Prompt 3.
15. Botones del login se mantienen más grandes por usabilidad.
16. Responsive básico.

Mapa de uso recomendado:
- Morado: acción principal, detalle, guardar, gestionar.
- Azul outline: editar, volver, recargar, limpiar, consultar.
- Verde: aprobar, activar, iniciar, crear toma.
- Rojo: eliminar, desactivar, cancelar, denegar.
- Amarillo: pendiente, regresar, devolución.
- Cian/Azul sólido: filtrar, descargar, información.

Este estándar será refinado pantalla por pantalla en los siguientes prompts.
