FIX PROMPT 9 - HOME.RAZOR @media

Fecha: 2026-07-02 20:38:31

Problema:
En archivos Razor, @media dentro de <style> se interpreta como expresión C#.
Eso generaba errores:
CS0103: El nombre 'media' no existe en el contexto actual.

Corrección:
- Home.razor: se reemplazó @media por @@media.
- ToolDetail.razor: se corrigieron accesos nullable puntuales en markup.

Resultado esperado:
- El Admin Web debe compilar nuevamente.
- El Dashboard debe conservar los estilos del Prompt 9.
