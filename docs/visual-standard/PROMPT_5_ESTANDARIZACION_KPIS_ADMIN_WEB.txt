PROMPT 5: ESTANDARIZACIÓN DE KPIs COMPACTOS DEL ADMIN WEB

Fecha: 2026-07-02 17:53:03

Objetivo:
Unificar todos los KPIs del Admin Web con diseño compacto, claro y consistente.

Archivo modificado:
- src/Navi.ToolsAssets.Admin/wwwroot/app.css

Reglas visuales aplicadas:
1. KPI compacto con altura mínima aproximada de 56px.
2. Card blanca con borde suave.
3. Borde lateral de color según tipo de indicador.
4. Título pequeño en mayúscula.
5. Número destacado, pero no exagerado.
6. Subtítulo pequeño.
7. Menor separación entre KPIs.
8. Grids responsive.
9. Colores semánticos:
   - Morado: total/general.
   - Verde: disponible/aprobado/correcto.
   - Azul: información/proceso/documentos.
   - Amarillo: pendiente/validación.
   - Rojo: bloqueado/dañado/rechazado.
   - Cian: soporte/exportación.
   - Gris: sin datos/neutro.
10. KPIs del encabezado no deben romper el hero.
11. Dashboard, Reportes, Documentos, Toma Física, Conciliación e Inventario quedan bajo el mismo patrón.
12. No se modifica lógica de negocio.

Este estándar será refinado por pantalla en los siguientes prompts.
