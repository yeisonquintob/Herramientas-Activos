Objetivo:
Unificar visualmente los badges/chips de estado y reforzar traducciones de estados técnicos a español.

Reglas visuales:
1. Badge compacto.
2. Estados positivos en verde.
3. Estados pendientes en amarillo.
4. Estados de error/rechazo/daño en rojo.
5. Estados de proceso/asignación en azul.
6. Estados de inconsistencia/sincronización parcial en morado.
7. Estados inactivos/no localizados/baja en gris.
8. Estados técnicos deben mostrarse en español desde el helper NaviStatusLabels.

- Available -> Disponible

- NotLocated / Lost -> No localizada
- PendingValidation -> Pendiente validación
- Disposed -> Dada de baja
- PendingDisposal -> Pendiente baja
- Validated -> Validado
- Synced -> Sincronizado
- NotSynced -> No sincronizado
- Draft -> Borrador
- InReview -> En revisión
- Approved -> Aprobado
- Rejected -> Rechazado
- Canceled / Cancelled -> Cancelado
- InProgress -> En progreso
- Finished -> Finalizada
