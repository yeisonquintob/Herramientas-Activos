PHASE 5.38 - MOBILE PHYSICAL PROGRESS AND PERMISSIONS

Fecha: 2026-07-09 17:21:14

Cambios aplicados:
- Toma física móvil principal:
  - El avance ahora calcula herramientas asignadas gestionadas / herramientas asignadas.
  - Gestionadas incluye confirmadas, rechazadas, diferentes, dañadas o reportadas.
  - No listadas / extras no afectan el avance.
  - El KPI Encontradas pasa a Reportadas.
  - El KPI Faltantes pasa a Pendientes.
  - El detalle de cada toma muestra Total asignadas, Reportadas y Pendientes del usuario actual.
  - Se carga resumen del participante actual por toma desde participants-board.
  - Administrador puede ver todas las tomas, pero el avance móvil se calcula sobre sus activos propios.
- Detalle de toma física:
  - CurrentParticipant ahora siempre toma el participante propio.
  - Ya no usa fallback al primer participante para administradores.
  - Avance usa CountedItems o, como respaldo, Found + Missing + Different + Damaged.
  - ExtraItems queda excluido del avance.
- Permisos:
  - El acceso al módulo móvil de toma física depende de PhysicalCounts.View o admin.
  - Reportar no listados conserva PhysicalCounts.Report.
  - Cargar evidencia conserva PhysicalCounts.Evidence.Upload.
  - Crear, iniciar, cerrar o cancelar tomas sigue fuera del móvil.
