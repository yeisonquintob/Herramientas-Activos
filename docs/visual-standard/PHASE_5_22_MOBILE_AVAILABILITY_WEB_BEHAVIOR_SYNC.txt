PHASE 5.22 - MOBILE AVAILABILITY WEB BEHAVIOR SYNC

Fecha: 2026-07-09 11:57:16

Objetivo:
- Alinear el módulo móvil Disponible y ubicación con el comportamiento funcional del aplicativo web.
- Mantener diseño móvil en tarjetas compactas.

Cambios:
- La pantalla móvil ya no se comporta como inventario simple.
- Se agrega flujo de gestión de ubicación similar al web:
  - seleccionar herramienta escribiendo código, nombre o serial.
  - seleccionar sede escribiendo código o nombre.
  - seleccionar almacén/taller/ubicación.
  - cambiar estado operativo según permiso.
  - guardar con validación de permisos.
- Se agregan KPIs equivalentes al web:
  - Total herramientas.
  - Disponibles.
  - Asignadas / prestadas.
  - En mantenimiento.
  - Sin ubicación.
- Se agregan chips por estado con conteo.
- Se corrige alcance por sede:
  - si el usuario tiene TODAS/ALL o rol admin, ve todas las sedes.
  - si no, ve solo su sede.
- Se corrigen permisos:
  - Ver: AssetAvailability.View.
  - Editar ubicación: AssetAvailability.Edit.
  - Cambiar estado: AssetAvailability.Status.Change.
- Se elimina Tools.View como permiso suficiente para ingresar a Disponible y ubicación.
- Se mantienen links a Detalle y Hoja de vida con returnUrl=/mobile/availability.
