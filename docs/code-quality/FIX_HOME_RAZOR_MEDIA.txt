FIX HOME.RAZOR - @media

Fecha: 2026-07-02 23:11:48

Problema:
Home.razor tenía reglas CSS @media dentro del bloque <style>.
En Razor eso se interpreta como código C# y genera:
CS0103: El nombre 'media' no existe en el contexto actual.

Corrección:
- Se reemplazó @media por @@media.
- Archivo corregido:
  src/Navi.ToolsAssets.Admin/Components/Pages/Home.razor

Cantidad corregida:
- Antes: 2
- Después sin escapar: 0

- ./build-admin.sh
