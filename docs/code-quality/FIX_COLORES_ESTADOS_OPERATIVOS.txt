FIX COLORES ESTADOS OPERATIVOS

Fecha: 2026-07-02 23:39:19

Motivo:
Los estados y acciones no tenían los mismos colores porque algunas pantallas usaban clases Bootstrap:
- badge bg-success
- badge bg-primary
- badge bg-danger
- badge bg-dark

Y otras usaban clases propias:
- assign-action-primary
- assign-action-success
- assignment-shelf-pill
- navi-status-badge

Corrección:
Se creó una paleta única:

- Disponible: verde
- Asignada / Asignar: azul
- En mantenimiento: cian
- Pendiente: amarillo
- Dañada: rojo
- No apta: rojo
- No localizada: gris oscuro
- Dada de baja: gris oscuro
