PHASE 5.24 - MOBILE AVAILABILITY RETURN BUTTONS

Fecha: 2026-07-09 12:32:42

Cambios:
- En Disponible y ubicación móvil se eliminan los botones:
  - Detalle
  - Hoja vida
- Se agregan botones:
  - Regresar taller
  - Regresar almacén
- Los botones dependen de seguridad:
  - Solo aparecen si el usuario tiene AssetAvailability.Edit.
- El botón Gestionar se conserva si el usuario tiene permiso para modificar:
  - AssetAvailability.Edit
  - AssetAvailability.Status.Change
- Regresar taller:
  - Busca ubicación de la sede con palabras clave: taller, mantenimiento, servicio.
  - Si el usuario también tiene AssetAvailability.Status.Change, cambia estado a InMaintenance.
- Regresar almacén:
  - Busca ubicación de la sede con palabras clave: almacén, bodega, herramientas.
  - Si el usuario también tiene AssetAvailability.Status.Change, cambia estado a Available.
- Si no encuentra ubicación destino, selecciona la herramienta para gestión manual.
- No se afecta el banner.
