PROMPT 13A - ESTANDARIZACIÓN DE BOTONES DE ACCIÓN

Fecha: 2026-07-03 11:33:45

Objetivo:
Unificar todos los botones de acción del Admin Web con el estilo aprobado de los botones Aprobar / Denegar.

Estilo aplicado:
- Botones compactos.
- Fondo suave.
- Borde visible.
- Texto fuerte.
- Sin sombras pesadas.
- Hover suave.
- Mismo alto, padding, radio y tipografía.

Colores:
- Morado suave: Asignar / Gestionar / Detalle / Principal.
- Verde suave: Aprobar / Confirmar / Guardar positivo.
- Rojo suave: Denegar / Rechazar / Eliminar / Anular.
- Naranja suave: Regresar / Devolver / Advertencia.
- Azul suave: Ver / Editar / Consultar / Descargar.
- Neutro: Limpiar / Volver / Secundario.
- Negro: Baja / cierre definitivo.

Protección:
- No se modifica el estilo de los botones dentro de banners.
- Los botones del banner conservan borde blanco y hover blanco.

Archivo:
- src/Navi.ToolsAssets.Admin/wwwroot/app.css

Compilación:
- ./build-admin.sh
