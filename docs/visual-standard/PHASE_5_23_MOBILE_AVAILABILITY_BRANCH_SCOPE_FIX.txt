PHASE 5.23 - MOBILE AVAILABILITY BRANCH SCOPE FIX

Fecha: 2026-07-09 12:13:53

Problema:
- Disponible y ubicación móvil mostraba todas las sedes a usuarios que no pertenecen a TODAS.
- La causa era que UserCanSeeAllBranches permitía alcance global por permisos como Settings.View/Settings.Manage.
- Esos permisos no representan alcance de todas las sedes.

Corrección:
- UserCanSeeAllBranches ahora solo retorna true si:
  - el usuario es ADMIN/SUPERADMIN;
  - BranchCode es TODAS o ALL;
  - BranchName es TODAS, ALL o Todas las sedes.
- Se elimina Settings.View / Settings.Manage como criterio de alcance global.
- IsSameBranch compara:
  - BranchId;
  - BranchCode;
  - BranchName.
- IsVisibleBranch compara:
  - BranchId;
  - BranchCode;
  - BranchName.
- IsVisibleLocation compara:
  - BranchId;
  - BranchCode;
  - BranchName.
- Si el usuario no tiene todas las sedes:
  - el filtro de sede se fija en su sede.
  - el input de sede queda bloqueado.
  - al limpiar filtros se conserva su sede.
- Se agregó una nota visual de alcance en filtros.
