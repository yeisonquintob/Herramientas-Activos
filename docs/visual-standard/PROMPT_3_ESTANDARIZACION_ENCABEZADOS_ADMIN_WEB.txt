PROMPT 3: ESTANDARIZACIÓN DE ENCABEZADOS DE PANTALLA

Fecha: 2026-07-02 17:28:28

Objetivo:
Unificar visualmente los encabezados de todas las pantallas del Admin Web.

Archivo modificado:
- src/Navi.ToolsAssets.Admin/wwwroot/app.css

Reglas visuales aplicadas:
1. Encabezado compacto de aproximadamente 92px de alto mínimo.
2. Fondo degradado negro/morado único.
3. Borde redondeado uniforme.
4. Pill superior compacto en mayúscula.
5. Título principal blanco, fuerte y compacto.
6. Descripción corta con fuente más pequeña.
7. Botonera derecha de 142px.
8. Botones de encabezado del mismo tamaño.
9. Si hay dos o más botones, van uno debajo del otro.
10. Botones blancos translúcidos con borde blanco.
11. Estados o contadores del encabezado compactos.
12. Responsive para pantallas pequeñas.
13. No se modifica lógica de negocio.

Este estándar será la base visual para:
- Dashboard
- Inventario
- Disponible y ubicación
- Asignación
- Historial
- Hoja de vida
- Documentos
- Reportes
- Configuración
- Usuarios
- Roles y permisos
- Tomas físicas
- Conciliación
- Compras
- Mantenimiento
