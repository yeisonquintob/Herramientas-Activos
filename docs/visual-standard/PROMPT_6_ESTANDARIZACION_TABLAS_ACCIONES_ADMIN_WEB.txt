PROMPT 6: ESTANDARIZACIÓN DE TABLAS Y ACCIONES DEL ADMIN WEB

Fecha: 2026-07-02 17:56:01

Objetivo:
Unificar todas las tablas y columnas de acciones del Admin Web con un diseño compacto, claro y consistente.

Archivo modificado:
- src/Navi.ToolsAssets.Admin/wwwroot/app.css

Reglas visuales aplicadas:
1. Tablas compactas con fuente reducida y legible.
2. Encabezados de tabla en mayúscula, compactos y con línea inferior fuerte.
3. Filas con padding reducido.
4. Hover suave en filas.
5. Primera columna en negrita para códigos.
6. Estándar para códigos, nombres y subtítulos.
7. Badges compactos dentro de tablas.
8. Columna de acciones alineada a la derecha.
9. Botones de tabla de 25px de alto.
10. Acciones verticales compactas cuando existan varios botones.
11. Scroll horizontal controlado en tablas grandes.
12. Estados vacíos con caja punteada.
13. Ajustes para tablas densas: asignaciones, roles, usuarios, documentos, mantenimiento, reportes y conciliación.
14. Fechas, cantidades y dinero con alineación estable.
15. Responsive para pantallas pequeñas.
16. No se modifica lógica de negocio.

Uso esperado:
- Inventario
- Disponible y ubicación
- Asignación
- Historial
- Hoja de vida
- Documentos
- Reportes
- Compras y mantenimiento
- Tomas físicas
- Conciliación
- Usuarios
- Roles y permisos
